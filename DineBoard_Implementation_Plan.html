📋 Project Overview

DineBoard is a comprehensive, multi-tenant SaaS platform designed specifically for Indian restaurants. It combines table bookings, AI-powered ordering via WhatsApp, and complete restaurant management in one seamless platform.

Market Position

Unlike global competitors like Toast and SevenRooms, DineBoard is:

  • 🇮🇳 India-first: Built for Indian restaurants, GST support, Razorpay integration
  • 💬 WhatsApp-native: Customers order and book via WhatsApp - no app download needed
  • 🤖 AI-powered: Natural language understanding in Hindi, English, and Hinglish
  • 💰 Flexible pricing: Subscription + Commission model for scalability
  • 📱 Hardware-free: Complete cloud solution, no POS hardware required

Multi-Tenant Data Isolation

Row-Level Security (RLS): PostgreSQL automatically filters all queries by tenant_id. Even if code has a bug, the database physically prevents cross-tenant data access.

Application Layer

  • JWT token includes tenant_id
  • Tenant middleware sets session context
  • All queries scoped to tenant

Database Layer

  • RLS policies on every table
  • SET app.current_tenant on connection
  • Zero-trust enforcement

🗄️ Database Schema

Core Tables

👥 TENANTS

Restaurant accounts with configuration, WhatsApp number, subscription status, and payment settings.

💳 SUBSCRIPTION_PLANS

Basic/Pro/Enterprise plans with pricing, commission rates, feature limits, and capabilities.

💰 PLATFORM_COMMISSIONS

Commission tracking for each order/booking, collection method, and status.

👨‍💼 STAFF

Staff members with roles (owner/manager/waiter/chef/cashier) and permissions.

🍽️ MENU_ITEMS

Menu items with categories, veg/non-veg, pricing, images, and availability.

🪑 TABLES

Table configuration with capacity, section, seating combinations, and status.

📅 BOOKINGS

Table reservations with slots, guests, status, and reminder tracking.

🛒 ORDERS

Food orders with items, total, status, payment status, and GST calculation.

🎟️ PROMO_CODES

Discount codes with % or flat amounts, validity dates, max uses, and min order.

📄 INVOICES

Invoice records with GST details, items, amount, PDF URL, and send status.

💬 CONVERSATIONS

WhatsApp conversation threads with context, intent detection, and AI responses.

📝 CONVERSATION_MESSAGES

Individual messages in conversations with role (user/assistant) and content.

Key Design Features

  • UUID Primary Keys: No sequential IDs, ensures tenant isolation
  • Tenant Scoping: Every tenant-specific table has tenant_id foreign key
  • Soft Deletes: deleted_at columns for audit trail and data recovery
  • Timestamps: created_at and updated_at on all tables for tracking
  • Indexes: On frequently queried columns (tenant_id, status, date_time)
  • RLS Policies: PostgreSQL automatically enforces tenant boundaries
